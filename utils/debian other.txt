################ COMMANDS  ######################
• Ctrl + P : Previews the Previous command (acts exactly like the Up Arrow).
• Ctrl + N : Previews the Next command (acts exactly like the Down Arrow).
• Ctrl + R : Opens Reverse Search mode. Start typing any letters of a past command, and it will instantly autofill it. Press Ctrl + R again to cycle backward through matches.
